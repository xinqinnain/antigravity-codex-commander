# Frontend Page Ownership & Design Alignment

1. **Do Not Delegate Frontend Pages to GPT/Codex by Default**:
   - Unless the user **explicitly states** that GPT/Codex should build the frontend page (e.g., "让 GPT 来做前端页面" / "让 Codex 写前端"), NEVER assign frontend page / UI development to GPT/Codex.
   - All frontend page development is owned and implemented directly by you (Antigravity).

2. **Align on Visual Style & Details Before Coding Frontend**:
   - Whenever you are about to create or redesign a frontend page, you MUST first communicate with the user before writing frontend code to confirm:
     - Overall visual style / aesthetic direction (e.g., minimal, editorial, dashboard, dark/light, playful, cyberpunk, etc.)
     - Color palette, typography, and atmosphere
     - Layout structure, key sections, and screen/visual details (cards, imagery, animations, micro-interactions, responsive targets)
   - Only begin implementing the frontend page after aligning with the user on these details (or if the user explicitly tells you to proceed with your own judgment).
